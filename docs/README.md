# Documentation

Quatre publics, quatre entrées.

## Pour la personne qui utilise l'outil

- **[GUIDE_CONSULTANTE.md](GUIDE_CONSULTANTE.md)** — le mode d'emploi complet.
  Aucune connaissance technique nécessaire. Faire passer un test, lire un
  résultat, le transmettre, utiliser la pige, télécharger une sauvegarde.
- **[Guide_utilisation_plateforme_tests.pdf](Guide_utilisation_plateforme_tests.pdf)**
  — le même, mis en page pour être imprimé.
- **[MODELES_COURRIELS.md](MODELES_COURRIELS.md)** — les courriels types à
  envoyer aux candidats, et ce qu'il vaut mieux ne pas écrire.

## Pour comprendre comment ça marche

- **[FONCTIONNEMENT_PIGE.md](FONCTIONNEMENT_PIGE.md)** — les sources, le
  dédoublonnage, les filtres et leurs raisons, le périmètre, les contacts.
- **[FONCTIONNEMENT_SAUVEGARDE.md](FONCTIONNEMENT_SAUVEGARDE.md)** — ce que
  contient une archive, comment restaurer, et pourquoi deux copies.
- **[ANALYSE_DES_QUESTIONS.md](ANALYSE_DES_QUESTIONS.md)** — comment l'outil
  mesure la qualité de ses propres questions.
- **[GUIDE_ENTRETIEN_IA.md](GUIDE_ENTRETIEN_IA.md)** — la fonction facultative
  qui appelle un modèle de langage, et les cinq garde-fous qui l'encadrent.

## Pour la conformité

- **[REGISTRE_TRAITEMENTS.md](REGISTRE_TRAITEMENTS.md)** — le registre des deux
  traitements : les tests candidats, et la prospection commerciale.
